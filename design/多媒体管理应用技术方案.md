### 2.2 相似度识别模块

#### 2.2.1 核心算法
- **感知哈希算法**：
  - 使用pHash（感知哈希）计算图片特征值
  - 对视频文件提取关键帧，计算每一关键帧的哈希值
  - 比较哈希值汉明距离，判断相似度

- **优化策略**：
  - 分阶段匹配：先使用低精度算法筛选，再使用高精度算法精匹配
  - 索引加速：建立哈希值索引，提高查询速度
  - 并行计算：利用多核CPU并行处理多个文件
  - 缓存机制：缓存已计算的哈希值，避免重复计算

#### 2.2.2 相似度计算流程
```
1. 输入图片预处理
2. 计算输入图片的pHash值
3. 遍历设备存储中的媒体文件
   a. 对图片文件：计算pHash值，与输入图片比较
   b. 对视频文件：提取关键帧，计算每一关键帧的pHash值，与输入图片比较
4. 计算相似度得分（0-100）
5. 按相似度得分排序
6. 展示结果
```

#### 2.2.3 视频关键帧提取
- **提取策略**：
  - 基于帧间差异：提取差异较大的帧
  - 基于时间间隔：定期提取关键帧（如每2秒提取1帧）
  - 基于场景变化：检测场景切换，提取场景起始帧

- **优化策略**：
  - 限制提取帧数：每视频最多提取20帧
  - 自适应提取：根据视频长度调整提取频率
  - 并行处理：多视频并行提取关键帧

### 2.3 媒体文件保护模块

#### 2.3.1 Android端实现

| 保护方式 | 实现方法 | 优缺点 |
|----------|----------|--------|
| **应用专用目录存储** | 使用`getApplicationInfo().dataDir`或`Context.getExternalFilesDir()`存储文件 | 优点：系统默认保护，其他应用无法访问；缺点：应用卸载时文件会被删除 |
| **文件权限设置** | 设置文件权限为`-rw-------`，仅允许应用自身访问 | 优点：实现简单；缺点：有root权限的应用可能绕过 |
| **文件加密** | 使用AES-256加密文件内容 | 优点：安全性高；缺点：增加存储和处理开销 |
| **文件隐藏** | 在文件名前添加"."或将文件移动到隐藏目录 | 优点：实现简单；缺点：容易被显示隐藏文件的文件管理器发现 |

**推荐方案**：
- 使用应用专用目录存储媒体文件
- 结合文件加密提高安全性
- 对敏感文件添加隐藏属性

#### 2.3.2 Windows端实现

| 保护方式 | 实现方法 | 优缺点 |
|----------|----------|--------|
| **文件属性设置** | 设置文件为"只读"和"隐藏"属性 | 优点：实现简单；缺点：用户可手动修改属性 |
| **NTFS权限设置** | 限制文件的删除权限 | 优点：安全性高；缺点：需要管理员权限 |
| **文件加密** | 使用EFS或第三方加密工具加密文件 | 优点：安全性高；缺点：增加处理开销 |
| **专用文件夹** | 创建应用专用文件夹，设置访问权限 | 优点：集中管理；缺点：需要适当的权限设置 |

**推荐方案**：
- 设置文件为"只读"属性
- 结合"隐藏"属性提高安全性
- 使用应用专用文件夹集中管理

```dart
import 'package:image/image.dart' as img;
import 'dart:math';

String calculatePHash(Uint8List imageData) {
  // 1. 加载图片
  final image = img.decodeImage(imageData);
  if (image == null) return '';
  
  // 2. 缩小尺寸为32x32
  final resized = img.copyResize(image, width: 32, height: 32);
  
  // 3. 转换为灰度图
  final grayImage = img.grayscale(resized);
  
  // 4. 计算DCT变换
  final dct = _calculateDCT(grayImage);
  
  // 5. 取8x8低频区域
  final lowFreqDCT = <double>[];
  for (int i = 0; i < 8; i++) {
    for (int j = 0; j < 8; j++) {
      lowFreqDCT.add(dct[i][j]);
    }
  }
  
  // 6. 计算平均值
  final avg = lowFreqDCT.reduce((a, b) => a + b) / lowFreqDCT.length;
  
  // 7. 生成哈希值
  String hash = '';
  for (final value in lowFreqDCT) {
    hash += value >= avg ? '1' : '0';
  }
  
  return hash;
}
```

#### 5.1.2 相似度比较
```dart
int calculateHammingDistance(String hash1, String hash2) {
  if (hash1.length != hash2.length) return -1;
  
  int distance = 0;
  for (int i = 0; i < hash1.length; i++) {
    if (hash1[i] != hash2[i]) {
      distance++;
    }
  }
  
  return distance;
}

double calculateSimilarity(String hash1, String hash2) {
  final distance = calculateHammingDistance(hash1, hash2);
  if (distance == -1) return 0.0;
  
  // 哈希长度为64位，相似度范围0-100
  return ((64 - distance) / 64) * 100;
}
```

### 5.2 文件保护机制实现

#### 5.2.1 Android端文件保护
```dart
import 'package:path_provider/path_provider.dart';
import 'dart:io';

Future<void> protectFile(String filePath) async {
  // 1. 检查文件是否存在
  final file = File(filePath);
  if (!await file.exists()) {
    throw FileSystemException('File not found', filePath);
  }
  
  try {
    // 2. 设置文件权限为只读
    await Process.run('chmod', ['400', filePath]);
    
    // 3. 如果是应用外部文件，考虑移动到应用专用目录
    final appDir = await getApplicationDocumentsDirectory();
    if (!filePath.startsWith(appDir.path)) {
      final newPath = '${appDir.path}/${file.uri.pathSegments.last}';
      await file.copy(newPath);
      await file.delete();
      
      // 更新数据库中的文件路径
      await _updateFilePathInDatabase(filePath, newPath);
    }
    
    // 4. 更新文件保护状态
    await _updateFileProtectionStatus(filePath, true);
  } catch (e) {
    // 如果设置权限失败，尝试隐藏文件
    await _hideFile(filePath);
  }
}

Future<void> _hideFile(String filePath) async {
  final file = File(filePath);
  final parentDir = file.parent;
  final newName = '.${file.uri.pathSegments.last}';
  final newPath = '${parentDir.path}/$newName';
  
  await file.rename(newPath);
  await _updateFilePathInDatabase(filePath, newPath);
  await _updateFileProtectionStatus(newPath, true);
}
```

#### 5.2.2 Windows端文件保护
```dart
import 'dart:io';
import 'package:win32/win32.dart' as win32;

Future<void> protectFile(String filePath) async {
  // 1. 检查文件是否存在
  final file = File(filePath);
  if (!await file.exists()) {
    throw FileSystemException('File not found', filePath);
  }
  
  try {
    // 2. 设置文件属性为只读和隐藏
    final pathPtr = win32.toUtf16(filePath);
    final attributes = win32.GetFileAttributesW(pathPtr);
    
    if (attributes != win32.INVALID_FILE_ATTRIBUTES) {
      final newAttributes = attributes | win32.FILE_ATTRIBUTE_READONLY | win32.FILE_ATTRIBUTE_HIDDEN;
      win32.SetFileAttributesW(pathPtr, newAttributes);
    }
    
    // 3. 更新文件保护状态
    await _updateFileProtectionStatus(filePath, true);
  } catch (e) {
    // 处理异常
    rethrow;
  }
}
```

### 5.3 应用重启后保护状态恢复

```dart
Future<void> restoreFileProtection() async {
  // 1. 从数据库获取所有受保护文件
  final protectedFiles = await _db.query('files', where: 'is_protected = ?', whereArgs: [1]);
  
  // 2. 遍历所有受保护文件，重新应用保护机制
  for (final file in protectedFiles) {
    final path = file['path'] as String;
    final fileObj = File(path);
    
    if (await fileObj.exists()) {
      try {
        await protectFile(path);
      } catch (e) {
        // 记录错误，但继续处理其他文件
        print('Failed to restore protection for $path: $e');
      }
    } else {
      // 文件不存在，从数据库中移除
      await _db.delete('files', where: 'id = ?', whereArgs: [file['id']]);
    }
  }
}
```

## 8. 风险评估和应对措施

### 8.1 技术风险

| 风险 | 可能性 | 影响 | 应对措施 |
|------|--------|------|----------|

| 应用占用内存过高 | 中 | 应用崩溃，设备卡顿 | 优化内存管理，及时释放资源，实现懒加载 |

### 8.2 业务风险

| 风险 | 可能性 | 影响 | 应对措施 |
|------|--------|------|----------|
| 用户误操作导致文件丢失 | 中 | 用户数据丢失，信任度下降 | 实现操作确认机制，提供文件恢复功能，加强用户教育 |
| 应用被恶意破解，保护机制失效 | 低 | 用户文件泄露 | 加强应用安全性，实现代码混淆，定期更新保护机制 |
| 不同系统版本兼容性问题 | 中 | 部分用户无法使用全部功能 | 针对主流系统版本进行测试，实现优雅降级 |

### 8.3 法律风险

| 风险 | 可能性 | 影响 | 应对措施 |
|------|--------|------|----------|
| 应用被用于非法用途 | 低 | 法律责任，应用下架 | 明确用户协议，禁止非法用途，实现内容审核机制 |
| 侵犯用户隐私 | 低 | 用户投诉，法律诉讼 | 严格遵守隐私法规，明确隐私政策，仅收集必要数据 |
